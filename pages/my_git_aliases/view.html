My git aliases

These are the git alias that I use to add:

git config --global alias.ch checkout
git config --global alias.br branch
git config --global alias.all "add --all"
git config --global alias.com "commit -m"
git config --global alias.st status
git config --global alias.plo "pull origin"
git config --global alias.pho "push origin"
git config --global alias.fall "fetch --all"
