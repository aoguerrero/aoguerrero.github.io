HTML

Generic page structure:

<!DOCTYPE html>
<html lang="en">
  <head>
    <meta http-equiv="Content-Type" content="text/html; charset=UTF-8">
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <meta name="description" content="{description of the document}">
    <meta name="keywords" content="{comma separated keywords}">
    <title>{Pate Title}</title>
    <link rel="stylesheet" href="{path to style.css}">
    <link rel="icon" href="./favicon.ico" type="image/x-icon">
    <style>
      {In-page styles}
    </style>
    <script>
      {In-page javascript}
    </script>
    <script src="{path to script.js}" {nothing|async|defer}></script>
  </head>
  <body>
    <main>
        {Page content}
    </main>
  </body>
</html>
  • async: Script is executed as soon is downloaded.
  • defer: Script is executed until the complete document is downloaded (similar to put the script tag at the end of the document).
