How to disable any application in Android

Access ADB

adb shell

List installed packages

pm list packages

Disable specific package

pm disable-user --user 0 {}
# or
pm uninstall -k --user 0 {}

List disabled packages

pm list packages -d

Enable disabled package

pm enable {}
# or
pm install-existing {}

Use Cx Explorer to get the package name of an installed application:

android
