Node Installation on Windows

  • Unzip node contents and set environment variable NODE_HOME with the path.

  • Create subdirectories npm-global and npm-cache

  • Add %NODE_HOME% and %NODE_HOME%\npm-global to the PATH.

  • Execute:

npm config set prefix "%NODE_HOME%\npm-global"
npm config set cache "%NODE_HOME%\npm-cache"
  • Test with:
npm install -g minify
  • Check that the module is added to npm-global and that the minify command is available.
